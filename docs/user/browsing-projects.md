# Browse your projects

Select **Projects** in the sidebar, below the search box, to open a page listing every project in
your workspace. It is also available from the command palette as **Open projects**.

Each row names the project and the repository it belongs to, or its folder when the checkout is not
in a recognized repository. Rows also carry how many threads the project holds, when one of them was
last active, how many checkouts are grouped under the project, and which environment holds it when
that is not this machine.

Search narrows the list by project name, repository, folder path, and environment name.

To start work, hover a row and select the compose button to open a new thread in that project.
Selecting the row itself opens the project's own page, where you can rename it, choose its icon, set
the model new threads start with, and manage its scripts and checkouts.

Select **New project** to add a folder or clone a repository.

Projects are grouped the way the sidebar groups them, so several checkouts of one repository appear
as a single row. Change that under **Settings** if you would rather keep them separate.
